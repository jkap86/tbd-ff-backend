# Copy Invite Link - User Guide for Commissioners

## 🎯 Quick Start (30 seconds)

1. Open your league
2. Tap the menu button (≡) top right
3. Tap the **link icon** 🔗
4. Toast appears: "Invite link copied!"
5. Paste the link anywhere you want to share it

Done! ✅

## ❌ Troubleshooting

### Issue: Button doesn't appear in menu
**Reason:** You're not the commissioner
**Solution:** You must be the league creator to see this button

### Issue: "Must be logged in" error
**Reason:** You got logged out
**Solution:** Log back in, then try again

### Issue: "Only the commissioner..." error
**Reason:** You're trying to share someone else's league
**Solution:** Only the league creator can generate invite links

### Issue: Link doesn't copy
**Reason:** Network issue or API problem
**Solution:** Try again in a few seconds

### Issue: Friend can't join from link
**Reason:** They might already be in the league
**Solution:** Have them try clicking again, or check if they're already a member

## ❓ FAQ

**Q: Can I change the invite link?**
A: No, it's always the same format. But you can generate a new one anytime.

**Q: Does the link expire?**
A: No, invite links don't expire (for now).

**Q: Can non-commissioners generate links?**
A: No, only the league creator (commissioner) can generate invite links.

**Q: What if someone else gets the link?**
A: Anyone with the link can join the league. Make sure you only share with people you want!

**Q: Can I limit who joins?**
A: Not yet. For now, anyone with the link can join.

**Q: What if my league is full?**
A: People will get a "League is full" message when they try to join.

**Q: What if someone joins twice?**
A: They'll get an error. You can only be in a league once.
